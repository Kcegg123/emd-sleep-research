# EMD 與睡眠研究 — 互動演算法演示

經驗模態分解 (Empirical Mode Decomposition, EMD) 在睡眠腦波研究中的應用。

## 功能

- **EMD 演算法互動演示**：調整參數觀察信號分解過程
- **篩選過程動畫**：逐步觀察包絡線建構與 IMF 提取
- **睡眠階段分析**：各睡眠階段 EEG 特徵與 EMD 表現
- **HHT 時頻譜**：Hilbert-Huang Transform 時頻分析視覺化
- **參考文獻**：相關重要論文整理

## 技術

純靜態網站 (HTML + CSS + JavaScript)，使用 Chart.js 繪製圖表。
